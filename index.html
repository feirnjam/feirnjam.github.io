    <h1>隐私政策</h1>

    <p class="update-date">最后更新日期：2026年5月5日</p>


    <div class="section">

        <h2>引言</h2>

        <p>小法球App（以下简称“我们”或“本应用”）非常重视您的隐私和个人信息保护。本隐私政策旨在向您说明我们如何收集、使用、存储、共享和保护您的个人信息。请您在使用本应用前仔细阅读本政策，若您不同意本政策的任何内容，请立即停止使用。</p>

    </div>


    <div class="section">

        <h2>1. 核心原则：数据本地化与用户自主</h2>

        <p>本应用的核心设计原则是最大程度保护您的隐私：


        1.1 本地存储优先。您的所有聊天记录、生成的文书、证据清单、备忘录等数据，默认仅存储在您的设备本地。我们不会将这些数据上传至任何服务器，也不会对其进行收集或备份。


        1.2 API Key 由您自主配置。本应用不提供人工智能模型服务。若您需要使用 AI 对话及内容生成功能，您需要自行前往第三方平台（如 DeepSeek）申请 API Key，并在本应用中配置。该 API Key 仅存储在您的设备本地，我们不会读取、上传或分享您的 API Key。


        1.3 数据传输透明。当您使用 AI 功能时，您输入的内容会通过加密接口（HTTPS）直接从您的设备传输至您所配置的第三方 AI 服务商。我们在此过程中充当客户端工具，不会截留、存储或分析传输内容。</p>

    </div>


    <div class="section">

        <h2>2. 我们收集的信息</h2>

        <p>2.1 我们不收集的信息：

        · 我们不收集您的聊天记录、生成的文书、上传的图片或文件内容。

        · 我们不收集您的 API Key。

        · 我们不要求您注册账号，因此不收集手机号、邮箱、密码等个人身份信息（除非您主动通过反馈功能提供）。


        2.2 自动收集的信息：

        · 设备信息：设备型号、操作系统版本、网络类型等，用于适配和优化应用体验。

        · 广告标识符（IDFA）：用于广告归因和展示个性化广告。您可以在系统设置中关闭跟踪。

        · 日志信息：应用运行过程中产生的匿名化技术日志（如崩溃日志），用于排查故障。


        2.3 您主动提供的信息：

        · 当您使用意见反馈功能时，您可能主动提供手机号、邮箱或其他联系方式，以便我们与您沟通处理结果。</p>

    </div>


    <div class="section">

        <h2>3. 第三方服务的信息处理</h2>

        <p>为提供完整功能，本应用集成了以下第三方 SDK 或 API 服务。这些服务可能会直接接收或处理您的数据，其行为受各自隐私政策约束：


        · DeepSeek AI（深度求索）：当您使用 AI 对话、文书生成等功能时，您输入的内容会通过您配置的 API Key 加密传输至 DeepSeek 服务器，以生成 AI 回复。DeepSeek 对该数据的处理请参见其官方隐私政策。

        · 百度 OCR 文字识别：当您上传图片进行文字识别时，图片内容会加密传输至百度 AI 开放平台服务器。百度对该数据的处理请参见其官方隐私政策。

        · 百度语音识别：当您使用语音输入功能时，您的语音数据会加密传输至百度 AI 开放平台服务器。百度对该数据的处理请参见其官方隐私政策。

        · Google AdMob：用于展示开屏广告，会收集设备广告标识符（IDFA）、设备信息等。Google 对该数据的处理请参见其官方隐私政策。


        上述数据传输均通过 HTTPS 加密，我们不会在本地或中间环节存储这些数据。</p>

    </div>


    <div class="section">

        <h2>4. 权限申请与用途</h2>

        <p>本应用在提供特定功能时，可能会向您请求以下系统权限：

        · 通知权限：用于推送 AI 回复完成提醒。您可以随时在系统设置中关闭。

        · 麦克风权限：用于语音输入功能。仅在您主动点击录音按钮时请求，不会后台录音。

        · 相册权限：用于从相册选择图片上传（如证据照片）。仅在您主动选择图片时触发。

        · 相机权限：用于拍摄证据照片。仅在您主动选择拍照功能时触发。

        · 文件访问权限：用于从文件 App 选择文件上传（如 PDF）。仅在您主动选择文件时触发。

        · IDFA 跟踪权限：用于广告归因。首次启动时弹窗询问，您可以在「设置 - 隐私 - 跟踪」中随时修改。


        所有权限均为可选，您拒绝授权不会影响基本功能的使用。</p>

    </div>


    <div class="section">

        <h2>5. 信息的使用</h2>

        <p>我们仅在以下情形使用自动收集的匿名化信息：

        · 适配和显示：根据设备型号、系统版本进行 UI 适配。

        · 广告展示：利用 Google AdMob 展示开屏广告，以支持免费服务。

        · 故障排查：分析匿名化的崩溃日志，定位和修复 Bug。

        · 统计分析：匿名的使用数据用于优化产品体验（不包含任何个人身份信息）。</p>

    </div>


    <div class="section">

        <h2>6. 信息的存储与安全</h2>

        <p>6.1 您的聊天记录、文书、证据清单等核心数据仅存储在您的设备本地，由 iOS 系统提供的安全机制（沙盒隔离）保护。

        6.2 您通过反馈功能提供的联系方式等信息，仅用于与您沟通反馈处理结果，不会用于其他目的。

        6.3 所有网络传输均采用 HTTPS 加密。

        6.4 尽管我们采取了合理的安全措施，但互联网环境并非绝对安全，我们无法保证信息的绝对安全。</p>

    </div>


    <div class="section">

        <h2>7. 信息的共享与披露</h2>

        <p>7.1 我们不会向任何第三方出售、出租或交易您的个人信息。

        7.2 在法律法规要求或政府机关强制性要求的情况下，我们可能会披露必要的信息。

        7.3 除本政策明确说明的第三方服务外，我们不会将您的信息共享给其他任何公司、组织或个人。</p>

    </div>


    <div class="section">

        <h2>8. 儿童隐私保护</h2>

        <p>8.1 本应用不面向 14 周岁以下的儿童。若您是儿童，请在监护人指导下使用。

        8.2 若我们发现无意中收集了儿童个人信息，将尽快删除。</p>

    </div>


    <div class="section">

        <h2>9. 您的权利</h2>

        <p>根据相关法律法规，您享有以下权利：

        · 访问与查看：您的数据存储在本地，您可以随时在应用内查看。

        · 删除：您可以随时在应用内删除聊天记录、文书、证据清单等数据。

        · 撤回同意：您可以在系统设置中随时关闭已授权的权限（如通知、麦克风、相册、跟踪等）。

        · 清除数据：您可以在「我的 - 设置 - 账号管理」中一键清除所有本地数据，等效于注销，数据将被永久删除且不可恢复。

        · 投诉举报：您可以通过下方联系方式向我们反馈隐私相关问题。


        我们将在收到请求后 15 个工作日内予以回复。</p>
